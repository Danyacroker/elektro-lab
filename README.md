# ⚡ ЭлектроЛаб

Игра-тренажёр по электротехнике: собираешь схемы в 3D на монтажной панели, рядом автоматически строится принципиальная схема, а расчётное ядро в реальном времени показывает токи, напряжения и последствия ошибок (КЗ, перегрузка, сгоревший провод, удар током).

## Запуск на своём компьютере

Проще всего — двойной клик по файлу `start.bat`: он запустит сервер и откроет игру в браузере. Окно с сервером должно оставаться открытым, пока вы играете. После перезагрузки компьютера сервер нужно запускать заново.

То же самое вручную (нужен только Node.js, он уже установлен):

```bash
node serve.mjs
```

Затем открыть http://localhost:8790

(Просто открыть `index.html` двойным кликом нельзя — браузер не загружает модули с диска. Интернет для игры не нужен: библиотека Three.js лежит в папке `vendor/`.)

## Как дать доступ друзьям

Игра — набор обычных файлов без серверной части, поэтому её достаточно выложить на любой статический хостинг. После этого она открывается по ссылке на компьютере, планшете и телефоне, а прогресс каждого игрока хранится в его браузере.

### Вариант 1. Netlify Drop — быстрее всего, без установки программ

1. Открыть https://app.netlify.com/drop и войти (можно через Google).
2. Перетащить папку `elektro-lab` целиком в окно браузера.
3. Через полминуты появится ссылка вида `https://случайное-имя.netlify.app` — её и отправлять друзьям. Имя можно поменять в настройках сайта.

Чтобы обновить игру — перетащить папку ещё раз в раздел Deploys этого сайта.

### Вариант 2. GitHub Pages — удобно, если игра будет дорабатываться

1. Создать репозиторий на https://github.com и загрузить в него содержимое этой папки (кнопка «Add file → Upload files» или через git).
2. В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.

Подойдут и Cloudflare Pages, Vercel — любой хостинг статических файлов. Сборка не требуется.

### Вариант 3. Только в своей сети Wi-Fi, без публикации

```bash
node serve.mjs 8790 lan
```

Сервер напечатает адрес вида `http://192.168.x.x:8790` — его можно открыть с телефона или планшета, подключённого к той же сети, пока запущен сервер. Windows при первом запуске спросит разрешение брандмауэра.

### Что уже сделано для телефонов и планшетов

- вёрстка перестраивается на узком экране: палитра — горизонтальной лентой, панель целей и параметров — снизу, её можно свернуть;
- управление касаниями: одним пальцем — сдвиг вида, двумя — масштаб и поворот; клеммы имеют увеличенную область нажатия;
- сайт можно «установить» как приложение (меню браузера → «Добавить на главный экран»), после первого открытия он работает без интернета.

Для сборки схем удобнее планшет или компьютер: на телефоне мелко.

| `js/scene3d.js` | 3D-сцена: постановка устройств, прокладка проводов, анимация тока |
| `js/schematic.js` | Автоматическая принципиальная схема (SVG) |

| `js/readmode.js`, `js/readtasks.js`, `js/readui.js` | Режим «Чтение схем»: по схеме собрать сборку и по сборке нарисовать схему, три уровня сложности; сравнение схем по соединениям |
| `js/defs4.js`, `js/models_e.js` | Проходная клемма и шина N / PE |
| `js/diag.js` | «Инспектор»: поиск ошибок монтажа, при которых схема работает, но собрана опасно (PE вместо нуля, аппарат в нуле, линия без защиты и др.) |
| `js/labs.js`, `js/labui.js` | Лабораторные работы: 12 вариантов, допуск, расчёт до опыта, таблица измерений, график, отчёт с оценкой |
| `js/levels3.js` | Квесты «Приёмка» — исправление чужих ошибок монтажа |

| `test/` | Проверки: `sim.test.mjs` и `dev2.test.mjs` (физика), `levels.test.mjs` и `levels2.test.mjs` (проходимость квестов), `diag.test.mjs` (инспектор), `labs.test.mjs` (лабораторные по всем вариантам), `readmode.test.mjs` (сравнение схем), `route.test.mjs` (провода не проходят через устройства), `dev3.test.mjs` и `levels4.test.mjs` (бытовая электрика, аварии, характеристики автоматов) — запуск `node test/<имя>` |

## Упрощения модели

Это учебная модель, а не инженерный расчёт:

- считаются действующие значения (без переходных процессов и формы синусоиды);
- время нагрева автоматов, проводов и двигателей ускорено в десятки раз, чтобы не ждать минутами;
- выпрямитель — усреднённая модель (0,9·U без фильтра, 1,41·U с фильтром);
- двигатель — упрощённая схема замещения с пусковым током 6·Iн.

Номиналы, допустимые токи кабелей и пороги срабатывания близки к реальным, но для настоящего проекта пользуйтесь ПУЭ и каталогами производителей.
